# hyper-publisher-legal

Versión pública de los documentos legales existentes de Señal Residual Publisher.

## Instalación en GitHub Pages

1. Crear repositorio público `hyper-publisher-legal`.
2. Subir `index.html` y `eliminacion-datos.html` a la raíz de la rama `main`.
3. GitHub: Settings → Pages → Deploy from a branch → `main` → `/(root)` → Save.
4. Abrir ambas URLs en una ventana privada:
   - `https://USUARIO.github.io/hyper-publisher-legal/`
   - `https://USUARIO.github.io/hyper-publisher-legal/eliminacion-datos.html`
5. Introducir la URL de la política en Meta for Developers.

## Avisos de sincronización

- Este sitio se derivó del HTML local proporcionado (versión 1.2.0), pero no es un duplicado exacto: se modificó el texto que decía que nunca se publicaría en la web, se retiraron los metadatos personales de aceptación y el SHA-256 de la versión local, y se eliminaron los enlaces a `127.0.0.1` de la navegación.
- La página pública conserva el contacto presente en el documento original. El email será visible a todos los visitantes; cámbialo por un correo de soporte si prefieres no publicar ese correo.
- Antes de publicar, comparar los detalles de almacenamiento, permisos, retención y borrado con la versión actual del código.
- No se adjuntaron términos de uso originales. Si quieres publicar los términos, aporta el documento original para evitar inventarlo.
- Si actualizas la política local de la aplicación, actualiza también esta copia pública. El hash mostrado en la aplicación puede dejar de corresponder a esta versión web, por eso se omitió.
